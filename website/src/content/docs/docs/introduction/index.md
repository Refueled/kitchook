---
title: What KitchooK! is
description: A simple static site generator for your Markdown recipe collection.
---

KitchooK! turns a folder of Markdown recipes and photos into a fast, searchable website you can host yourself. It checks supported recipe fields and image references, optimizes referenced photos, and builds the pages and client-side search data ahead of time.

Your collection remains plain text files and photos on your drive. KitchooK! builds a website from those files without changing them.

- **No database required:** The published site contains static HTML, CSS, JavaScript, optimized images, search data, and JSON.
- **Build it your way:** Build locally with Node.js, use the Docker builder, or automate builds with GitHub Actions.
- **Keep the source private:** KitchooK! does not require a public repository or hosted content service. If the built cookbook is private too, protect access at the static host.

Check out the [live demo](https://demo.kitchook.com) or read the [quick start](/docs/introduction/quick-start/).
